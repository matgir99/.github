# Default community files

This public repository provides **default contribution guidelines for repositories owned by the personal GitHub account [matgir99](https://github.com/matgir99)**. It is separate from any organization-owned repositories.

## Default guidelines

- [CONTRIBUTING.md](CONTRIBUTING.md) — branching, pull requests, CI, releases, security, and AI-assisted contributions.

GitHub automatically offers these guidelines for **public and private repositories** owned by this account that do not have their own \`CONTRIBUTING.md\`. An individual repository's own contribution guidelines take precedence.

The README itself is informational: **GitHub uses \`CONTRIBUTING.md\`, not this README, as the default contribution policy.**

## How to contribute

The usual route is a task-specific branch → pull request to \`develop\` → a release-ready pull request from \`develop\` to \`main\`. Smaller repositories may omit \`develop\`. Always check repository-specific instructions.

## Enforcement and scope

Default community files share instructions; **they do not configure or enforce branch protection, required checks, access permissions, or CI/CD workflows**. Each repository must be configured separately where GitHub supports those controls. Contributors must follow the guidelines even when a technical restriction is unavailable.

The owner's detailed administrative policy and implementation checklist are maintained privately, not published in this repository.

[GitHub documentation: default community health files](https://docs.github.com/en/communities/setting-up-your-project-for-healthy-contributions/creating-a-default-community-health-file).
